# 크리처 씨앗을 캐세요! 재방문 문제 분석

한 줄 요약: 출시 첫 주 약 1,500명이 들어온 Roblox 게임에서, 신규 유저의 절반이 첫 씨앗을 줍기 전에 떠나는 문제를 데이터로 찾아 튜토리얼을 고쳤고(첫 씨앗 발굴 53% → 82%), 다음 날 재방문(D1 4.4% → 4.5%)은 그대로라 보상 구조를 다시 손봤습니다.

## 1. 문제 정의

**대상과 문제 한 문장**
첫 접속한 신규 유저가, 튜토리얼 안에서 첫 씨앗을 줍기 전에 떠나고(47%), 첫 5분을 넘겨도 다음 날 다시 들어오지 않는다(D1 4.4%).

**비즈니스 임팩트**
- 광고(스폰서)로 노출된 약 73만 명 중 1,321명(0.18%)이 들어왔고, 신규의 87.9%가 광고로 왔습니다. 들어온 사람이 첫 5분에서 빠지면 광고비가 그대로 사라집니다.
- 하루만 오고 끝난 유저가 94.6%입니다. 재방문이 없으면 코인·펫 알 결제도 일어나지 않습니다. 결제 창을 연 90명 중 실제로 산 사람은 4명입니다.

**성공 기준**
| 단계 | 기준 |
|---|---|
| 첫 5분 | 첫 씨앗 발굴 비율, 1분 안 이탈 비율이 출시판보다 좋아짐 |
| 재방문 | D1(다음 날 다시 접속) 재방문율이 출시판보다 오름 |
| 결제 | 결제 창을 연 사람 중 실제 구매 비율이 오름 |

**Focus 지표와 선행지표**
- Focus 지표: D1 재방문율
- 선행지표: 첫 씨앗 발굴 비율(첫 5분), 첫날 플레이 60분 이상 비율

## 3. 분석과 검증

### Q1. 사람들은 어디서 가장 많이 들어올까? (현황 파악, 가설 없음)

| 유입 | 인원 | 비율 |
|---|---|---|
| 스폰서 광고 | 1,321명 | 87.9% |
| 친구 | 115명 | 7.7% |
| 기타 | 38명 | 2.5% |
| 검색 | 27명 | 1.8% |
| 숨은 추천 | 1명 | 0.1% |

- 사실: 신규 대부분이 광고로 들어왔습니다. 광고 노출 약 73만 명 중 들어온 비율은 0.18%입니다.
- 해석: 친구가 하는 게임에 버튼 한 번으로 따라 입장하는 구조라, 친구 유입(레퍼럴)이 특히 중요한 게임입니다.

### Q2. 5분 안에 떠나는 사람은 어디서 이탈할까? (가설 2: 채택)

가설: 튜토리얼이 복잡하거나 이해하기 어려워서 첫 씨앗을 줍기 전에 떠날 것이다.

- 사실: 출시 이후 신규 160명 중 75명(47%)이 첫 씨앗을 줍기 전에 나갔고, 끝까지 마친 사람은 41명(25.6%)이었습니다.
- 개선: 튜토리얼을 4차에 걸쳐 고쳤습니다(1차 첫 씨앗 안내·강화 단계, 2차 완료 축하·상점 둘러보기, 3차 첫 5분 개편).

| 지표 | 출시판(160명) | 개편 후(389명) |
|---|---|---|
| 첫 씨앗 발굴 | 53% | 82% |
| 1분 안 이탈 | 41% | 27% |
| 건너뛰기 | 23% | 5% |
| 첫날 강화 | 13% | 42% |

- 검증: 비율 차이 검정 z = 6.9, p < 0.01
- 한계: 개편 전후를 비교한 것이라 같은 기간 광고 유입량과 요일이 함께 바뀌었습니다(5장).

### Q3. 다음 날 다시 접속하는 사람은 얼마나 될까? (가설 3-1 채택, 3-2 기각)

- 사실: 첫 5분은 고쳐졌지만 D1은 4.4% → 4.5%로 차이가 없었습니다. 하루만 오고 끝난 비율은 94.6%입니다.
- **가설 3-1 (채택)**: 첫날 오래 플레이한 사람은 다음 날 다시 온다.

| 비교 | 다음 날 재접속 |
|---|---|
| 첫날 60분 넘게 플레이 | 43% |
| 첫날 5분 미만 | 약 2% |
| 출석 보상 받음 / 안 받음 | 7.0% / 1.9% |
| 퀘스트 보상 받음 / 안 받음 | 9.3% / 2.3% |
| 첫날 삽 단계 3단계 / 4단계 이상 | 10.9% / 34.6% |

- **가설 3-2 (기각)**: 랜덤 씨앗을 주면 궁금해서 다음 날 다시 온다. 미스터리 씨앗을 받은 사람의 D1은 개편 전 4.6%(196명 중 9명), 개편 후 8.3%(145명 중 12명)로 올랐지만 통계적으로 의미가 없었습니다(p = 0.16).
- 해석: 오래 하면 다시 오지만, "오래 하게 만드는 것"이 아직 없습니다. 보상이 다시 올 이유가 되는지는 이 데이터만으로 알 수 없습니다.

### Q4. 사람들은 무엇을 사려고 결제 창을 열까? (가설 4: 기각)

가설: 유료 아이템은 편의 상품 위주로 찾을 것이다.

| 상품 종류 | 본 사람 | 비율 |
|---|---|---|
| 펫 알 | 52명 | 58% |
| 편의 | 37명 | 41% |
| 코인 | 15명 | 17% |
| 기타 | 12명 | 13% |

- 사실: 신규 1,473명 중 결제 창을 연 사람은 90명이고, 그중 펫 알을 본 비율이 58%로 가장 높았습니다. 실제로 산 사람은 4명입니다.
- 한 사람이 여러 종류를 열 수 있어 합이 100%를 넘습니다.
- 해석: 사람들은 플레이를 편하게 해 주는 상품보다 펫을 뽑는 상품을 더 찾았습니다.

## 4. 해결책

| 어느 분석에서 | 한 일 | 움직이려는 지표 |
|---|---|---|
| Q2 | 튜토리얼 4차 개편(첫 씨앗 안내, 완료 축하, 상점 둘러보기, 첫 5분 개편) | 첫 씨앗 발굴 53% → 82%(달성) |
| Q3 | 다시 올 이유 추가: 출석·퀘스트·접속 보상과 펫 입양 콘텐츠 | D1 재방문율(4.4% → 4.5%, 아직 변화 없음) |
| 접속 보상 분석 | 접속 보상의 코인 2배 칸 삭제, 퀘스트 보상 코인 2배 → +20%, 가방 한도 추가 | 보상을 한꺼번에 파는 행동 줄이기 |
| Q4 | 펫 알 상품부터 다듬을 계획 | 결제 창 → 구매 전환(35% → 0.3% 문제 해소) |

- 접속 보상을 고친 이유: 코인 2배 시간에 크리처를 모았다가 한꺼번에 파는 사람이 나왔습니다. 상위 10명이 전체 코인의 84%를 획득했습니다.
- 남은 과제: 첫 씨앗 3개를 줍는 구간 다듬기, 유료 상점은 열어 보는데 사지 않는 문제(35% → 0.3%).

## 5. 한계

1. 보상 수치를 평균 유저 기준으로 잡아서, 헤비 유저가 보상을 몰아 쓰는 것을 예상하지 못했습니다.
2. 개편 전후를 비교한 것이라 인과를 단정할 수 없습니다. 같은 기간 광고 유입량과 요일도 함께 바뀌었고, 다음에는 A/B 테스트로 확인할 예정입니다.
3. 재방문(D1) 인원이 적어 개편 효과를 판단하기 어렵습니다. D1 4.4% → 4.5%는 차이도 작고 인원도 적습니다.

## 6. 실행법과 폴더 구조

게임 코드와 수신 서버는 별도 저장소에 있습니다(Rojo로 관리하는 Roblox 프로젝트).

```
my-game/
├─ src/
│  ├─ server/      게임 서버 로직, Analytics(이벤트 기록)
│  ├─ client/      화면·연출
│  └─ shared/      공용 설정표
├─ tools/ingest/   BigQuery 수신 서버(Cloud Run)
└─ docs/analytics-bigquery.md   이벤트 정의와 조회 예시
```

분석 쿼리 실행:
```bash
bq query --use_legacy_sql=false 'SELECT ... FROM `sesac-sd-bigquery-jun.roblox_game.events` WHERE event_time >= TIMESTAMP "2026-10-07"'
```
날짜 조건을 꼭 넣어 조회하세요(하루 단위 분할 테이블). 비밀 키는 저장소에 없고 Secret Manager에서 읽습니다.
