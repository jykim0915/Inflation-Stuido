## 1. 문제 정의

**문제 한 문장**
신규 유저가 튜토리얼에서 첫 씨앗을 줍기 전에 떠나고(47%), 남은 유저도 다음 날 다시 오지 않는다(D1 4.4%).

**임팩트**

| 사실 | 수치 |
|---|---|
| 스폰서 광고 노출 → 입장 | 약 73만 명 중 1,321명(0.18%) |
| 신규 중 광고 유입 비율 | 87.9% |
| 하루만 오고 끝난 유저 | 94.6% |
| 결제 창을 연 사람 → 실제 구매 | 90명 → 4명 |

**성공 기준**
- 첫 5분: 첫 씨앗 발굴 비율이 오르고 1분 안 이탈이 줄어든다.
- 재방문: D1 재방문율이 출시판(4.4%)보다 오른다.
- 결제: 결제 창을 연 사람 중 구매 비율이 오른다.

**지표**
- Focus 지표: D1 재방문율
- 선행지표: 첫 씨앗 발굴 비율, 첫날 플레이 60분 이상 비율

## 3. 분석과 검증

### Q1. 사람들은 어디서 들어올까? (현황 파악)

| 유입 | 인원 | 비율 |
|---|---|---|
| 스폰서 광고 | 1,321명 | 87.9% |
| 친구 | 115명 | 7.7% |
| 기타 | 38명 | 2.5% |
| 검색 | 27명 | 1.8% |
| 숨은 추천 | 1명 | 0.1% |

- **사실**: 신규 대부분이 광고로 들어왔습니다.
- **해석**: 친구가 하는 게임에 버튼 한 번으로 따라 입장하는 구조라 친구 유입(레퍼럴)이 특히 중요합니다.

### Q2. 첫 5분에 어디서 떠날까? (가설 2 채택)

가설: 튜토리얼이 어려워서 첫 씨앗을 줍기 전에 떠날 것이다.

- **사실**: 출시 이후 신규 160명 중 75명(47%)이 첫 씨앗 전에 나갔고, 끝까지 마친 사람은 41명(25.6%)입니다.
- **조치**: 튜토리얼을 4차에 걸쳐 개편했습니다.

| 지표 | 출시판 (160명) | 개편 후 (389명) |
|---|---|---|
| 첫 씨앗 발굴 | 53% | 82% |
| 1분 안 이탈 | 41% | 27% |
| 건너뛰기 | 23% | 5% |
| 첫날 강화 | 13% | 42% |

- **검증**: 비율 차이 검정 z = 6.9, p < 0.01
- **주의**: 개편 전후 비교라 같은 기간의 광고 유입과 요일 변화가 섞여 있습니다(5장).

### Q3. 다음 날 다시 올까? (가설 3-1 채택, 3-2 기각)

- **사실**: 첫 5분이 좋아졌지만 D1은 4.4% → 4.5%로 그대로입니다.

**가설 3-1 (채택)**: 첫날 오래 플레이한 사람은 다음 날 다시 온다.

| 비교 | 다음 날 재접속 |
|---|---|
| 첫날 60분 넘게 플레이 / 5분 미만 | 43% / 약 2% |
| 출석 보상 받음 / 안 받음 | 7.0% / 1.9% |
| 퀘스트 보상 받음 / 안 받음 | 9.3% / 2.3% |
| 삽 단계 3단계 / 4단계 이상 | 10.9% / 34.6% |

**가설 3-2 (기각)**: 랜덤 씨앗을 주면 궁금해서 다시 온다.
미스터리 씨앗을 받은 사람의 D1은 개편 전 4.6%(196명 중 9명), 개편 후 8.3%(145명 중 12명)로 올랐지만 통계적으로 의미가 없었습니다(p = 0.16).

- **해석**: 오래 플레이하면 다시 오지만, 오래 하게 만드는 장치가 아직 부족합니다.

### Q4. 결제 창에서 무엇을 볼까? (가설 4 기각)

가설: 유료 아이템은 편의 상품 위주로 찾을 것이다.

| 상품 종류 | 인원 | 비율 |
|---|---|---|
| 펫 알 | 52명 | 58% |
| 편의 | 37명 | 41% |
| 코인 | 15명 | 17% |
| 기타 | 12명 | 13% |

- **사실**: 신규 1,473명 중 결제 창을 연 90명을 상품 종류별로 나눴습니다. 한 사람이 여러 종류를 열 수 있어 합이 100%를 넘습니다.
- **해석**: 편의 상품(41%)보다 펫을 뽑는 상품(58%)을 더 찾았습니다.

## 4. 해결책

| 근거 | 한 일 | 지표 |
|---|---|---|
| Q2 | 튜토리얼 4차 개편 (첫 씨앗 안내, 완료 축하, 상점 둘러보기, 첫 5분 개편) | 첫 씨앗 발굴 53% → 82% |
| Q3 | 다시 올 이유 추가 (출석·퀘스트·접속 보상, 펫 입양 콘텐츠) | D1 4.4% → 4.5% (변화 없음) |
| 접속 보상 점검 | 접속 보상의 코인 2배 칸 삭제, 퀘스트 보상 코인 2배 → +20%, 가방 한도 추가 | 보상 몰아 쓰기 줄이기 |

- **보상을 고친 이유**: 코인 2배 시간에 크리처를 모았다가 한꺼번에 파는 사람이 나왔고, 상위 10명이 전체 코인의 84%를 획득했습니다.
- **남은 과제**: 첫 씨앗 3개를 줍는 구간 다듬기, 결제 창은 열어 보는데 사지 않는 문제(35% → 0.3%).

## 6. 실행법과 폴더 구조

게임은 Rojo로 관리하는 Roblox 프로젝트이며 코드는 별도 저장소에 있습니다.

```
my-game/
├─ src/
│  ├─ server/        게임 서버 로직, 이벤트 기록(Analytics)
│  ├─ client/        화면·연출
│  └─ shared/        공용 설정표
├─ tools/ingest/     BigQuery 수신 서버 (Cloud Run)
└─ docs/analytics-bigquery.md   이벤트 정의와 조회 예시
```

분석 쿼리 실행 예:

```bash
bq query --use_legacy_sql=false \
  'SELECT event_name, COUNT(*) n
   FROM `sesac-sd-bigquery-jun.roblox_game.events`
   WHERE event_time >= TIMESTAMP "2026-10-07"
   GROUP BY 1 ORDER BY 2 DESC'
```

날짜 조건을 꼭 넣어 조회하세요(하루 단위 분할 테이블). 비밀 키는 저장소에 없고 Secret Manager에서 읽습니다.
